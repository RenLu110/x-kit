# Changelog

## 2.0.0

- Rename the project to X Kit.
- Add six independent accessible sliding switches, plus enable-all/disable-all.
- Add local saved posts with categories, tags, notes, search, Markdown export and JSON backup/merge import.
- Add account annotations, stored locally by handle.
- Add exports of selected loaded posts and detected loaded article text, with source URLs and explicit partial-coverage notices.
- Add literal keyword/account noise rules with allowlists, folding and one-click reveal.
- Add a version handshake between the popup and the actual content script, and a reload button.
- Preserve existing follower-display and list-filter behavior.

## 1.1.0

- Add loaded-list filtering by keyword and follower range, count sorting and per-list isolation.

## 1.0.1

- Bundle each content-script entry independently to fix shared-helper startup failures.

## 1.0.0

- Initial follower-count badges.
