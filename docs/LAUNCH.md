# X 发布素材

状态：文案草稿，尚未代发。仓库已公开；首次安装包按预览版发布。配图 `assets/toolkit-demo.png` 使用示例数据，不是实际账号背书。

## 首帖草稿

刷 X 最浪费时间的几个动作：点进主页看粉丝数、翻关注列表找人、收藏以后再也找不到。

我把这些做成了一个开源插件：X Kit。

6 个功能：粉丝数显示、关注列表筛选、账号备注、收藏检索、内容导出、信息流降噪。

每个功能都有独立开关，想开几个就开几个。收藏和备注保存在本地，不需要 API Key。

先放一个预览版，欢迎试用和提问题：
https://github.com/RenLu110/x-kit

你刷 X 时最想省掉哪个重复动作？

## 补充回复草稿

安装方式：下载发布页的 ZIP → 解压 → Chrome 扩展管理页打开开发者模式 → 加载解压后的文件夹 → 刷新 X。

两个边界先说清楚：名单筛选只覆盖这次已浏览的账号；内容导出只包含已经加载的部分，不是自动抓全量数据。收藏库也和 X 原生书签分开管理。
